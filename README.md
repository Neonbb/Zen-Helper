# Zen-Helper v16 | Release Distribution

## Overview

PS Dual Launcher v16 is a lightweight, portable utility from the Zen Utility Toolkit, purpose-built for Project Sylvanas (PS) client multi-instance management. It allows users to run multiple PS client instances simultaneously on a single Windows system without duplicate client installations, and integrates built-in World of Warcraft (WOW) client file backup & restore functionality to protect addon configurations and interface customizations.

## Download

Official repository and latest release download:
[https://github.com/Neonbb/Zen-Helper](https://github.com/Neonbb/Zen-Helper)

## Core Features

- **Dual/Multi-Instance Launching**: Native support for parallel operation of multiple PS client instances, with automatic process isolation and independent profile separation.
- **WOW Client Backup**: One-click full backup for WOW client directories, with fast one-step restore capability.
- **Green & Portable**: No installation required, no system registry modifications, no additional runtime dependencies.
- **Low Overhead**: Minimal CPU and memory footprint at runtime, no resident background processes.
- **Windows Compatibility**: Optimized for Windows 10/11 desktop environments, compatible with mainstream PS client versions.

## v16 Update Notes

- Fixed process compatibility issues with the latest PS client patch.
